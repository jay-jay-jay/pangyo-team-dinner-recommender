# 🍽️ 판교테크노밸리 맞춤형 회식장소 추천 서비스 (Pangyo Team Dinner Recommender)

판교테크노밸리 직장인들을 위한 예산, 인원수, 룸/단체석, 판교역 접근성 및 평점 기반 맞춤형 회식장소 추천 웹 서비스입니다.

---

## 🌟 주요 기능

1. **우선순위 기반 다차원 스코어링**
   - 1인 목표 예산 적합도
   - 단독 룸 보유 및 단체석 수용 인원
   - 판교역 기준 거리 접근성
   - 리뷰 수 및 평점 가중합 (100점 만점)
   - 사이드바 가중치 슬라이더를 통한 실시간 순위 재계산

2. **일정 및 메뉴 필터링**
   - 회식 날짜(요일) 기준 정기 휴무일 자동 제외
   - 한식 / 중식 / 일식 / 양식 원클릭 필터

3. **인터랙티브 지도 시각화 (`pydeck`)**
   - 판교역 중심 2D/3D 지도 위젯
   - 마우스 호버 시 식당명, 도로명 주소, 위도/경도 좌표, 1인 예산, 평점 툴팁 제공
   - 식당별 상세 좌표 표 제공

4. **카카오맵 연동**
   - 식당별 카카오맵 공식 다이렉트 검색 및 상세 페이지 원클릭 바로가기

---

## 🛠️ 실행 방법

```bash
# 1. 가상환경 생성 및 활성화
python -m venv venv
.\venv\Scripts\Activate.ps1

# 2. 의존성 패키지 설치
pip install -r requirements.txt

# 3. Streamlit 앱 실행
streamlit run app.py
```

브라우저에서 `http://localhost:8501` 접속
